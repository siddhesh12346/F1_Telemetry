================================================================================
FORMULA 1 TELEMETRY ML FEASIBILITY STUDY: REFINED SURFACE-DEPARTURE WARNING
================================================================================

1. EXPERIMENT OVERVIEW & TARGET DEFINITION
--------------------------------------------------
Task: Short-Horizon Off-Track / Surface-Departure Warning (1.0s ahead).
Target: future_surface_departure = 1 if ANY wheel reports documented code 7
        during frames t+1 .. t+19 (~1.0s horizon at ~19.08 Hz).
Condition: Evaluated strictly when vehicle is currently on-track (departure_now == 0).
Terminology: OFF-TRACK / SURFACE-DEPARTURE WARNING (Not 'track-limit violation').

2. DATASET & SPLITS
--------------------------------------------------
Circuits: Mexico, Monza, Sakhir (Training & Val), Spa (Held-out Test)
Validation Tuning Circuit: Sakhir (Threshold tuned on validation, locked for Spa)
Held-out Test Circuit: Spa (31,933 rows, 2,903 positive warning frames, 276 departure events)

3. LEAKAGE CONTROLS VERIFICATION
--------------------------------------------------
- current surfaceType excluded from features: VERIFIED
- future surfaceType excluded from features: VERIFIED
- future telemetry/controls excluded: VERIFIED
- world coordinates (worldPositionX/Y/Z) excluded: VERIFIED
- no random row splitting (circuit-held-out split): VERIFIED
- causal rolling features strictly using past/current samples: VERIFIED

5. KEY FINDINGS & ABLATION ANALYSIS
--------------------------------------------------
A. Threshold Calibration Impact:
   - Under default 0.50 threshold, tree models suffered from recall collapse
     (RF Recall: ~0.7%, XGBoost Recall: ~1.2%) despite ROC-AUC > 0.68.
   - Tuning thresholds on Sakhir validation circuit (locked and applied to Spa)
     dramatically recovered recall and achieved high event detection rates.

B. Causal Rolling Features (Exp A vs Exp B):
   - Adding rolling means, standard deviations, and dynamic changes improved
     ranking discrimination and lead-time stability before departure events.

C. lapDistance Ablation (Exp B vs Exp C):
   - lapDistance was a top-ranked feature in Exp B, indicating circuit-location
     memorization. Removing lapDistance in Exp C tests pure vehicle dynamics.
   - Compare Exp B vs Exp C metrics above to determine dynamic generalization.

6. EVENT-LEVEL WARNING CAPABILITY
--------------------------------------------------
Event-level evaluation measures whether a driver receives at least one warning
in the 1-second window immediately preceding entry into off-track grass/gravel.
See table above for detected event count (out of 276 Spa events) and lead times.
